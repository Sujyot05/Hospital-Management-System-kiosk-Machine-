# Hospital Management System - Kiosk Machine

Hospital Management System - Kiosk Machine is an Android application developed using Java and Android Studio. The application uses Android WebView technology to provide a fast and efficient kiosk-based interface for accessing the Hospital Management System directly from Android devices.

### Project Description

This project is an extension of the Hospital Management System platform and includes an Android kiosk application designed for payment handling, patient interaction, and hospital workflow management.

### Features

* Android Webview integration
* Kiosk mode interface
* Lightweight and efficient application
* Fast connection to hospital management system
* Full screen Android application
* Java-based Android application
* User-friendly interface design

### Tech Stack

* Java
* Android Studio
* Android Webview
* XML
* Gradle

### Installation Steps

1. Clone the repository
